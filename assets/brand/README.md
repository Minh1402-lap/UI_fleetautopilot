# Fleet Autopilot identity

## Fleet logo preview — 2026-11-18

`fleet-logo-reference.png` is the unchanged reference supplied by the user. The primary logo combines the stylized F, dump truck, crane and construction materials. Preserve that full composition for large applications; do not force its fine details into the sidebar.

Current user direction supersedes the earlier cropped app-icon tile:

| Use | Identity treatment |
| --- | --- |
| Sidebar, all sizes | Simplified F only; editable inline SVG in `index.html`, no truck/crane/material details. |
| Light | Forest green `#1A2A20` / `#2E4D3A` on white. |
| Dark | Ivory `#E6EDE8` and muted moss on `#0B0F0D`. |
| Moss Lime | Same light mark on dark tile; `#8CCF4D` limited to a 3–4px accent dot. |
| Existing Amber | Ivory/moss mark; retain the surrounding approved amber UI. |

Suggested identity palette: `#0B0F0D`, `#1A2A20`, `#2E4D3A`, `#8CCF4D`, `#E6EDE8`. Branding tokens in `brand-preview.css` do not recolor the whole dashboard. The full logo remains the original reference, not a newly produced set of transparent primary-logo variants. Raster-generation drafts were excluded; the sidebar uses clean native SVG paths.

Scope: UI prototype only. Verification and feature code map: `tests/test-cases/logo-preview.md`.
